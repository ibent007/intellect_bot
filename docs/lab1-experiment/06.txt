1. Порядок элементов. Список сохраняет порядок, в котором элементы были добавлены. Множество не гарантирует порядок — элементы могут быть в любом порядке.

2. Повторяющиеся элементы. Список допускает дубликаты. Множество хранит только уникальные значения — повторный ввод того же элемента игнорируется.

3. Когда выбирать. Список — когда важен порядок или нужны дубликаты, например, список покупок, где яблоки могут быть дважды. Множество — когда нужны только уникальные значения, например, набор друзей, где каждый человек один раз.
