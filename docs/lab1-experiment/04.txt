1. Порядок элементов. Список сохраняет порядок, в котором элементы были добавлены. Множество не гарантирует порядок — элементы могут храниться в любом порядке.

2. Повторяющиеся элементы. Список допускает дубликаты. Множество хранит только уникальные значения — повторное добавление того же элемента игнорируется.

3. Когда выбирать. Список — когда важен порядок или нужны дубликаты (например, список оценок по предметам за семестр). Множество — когда нужны только уникальные значения (например, набор любимых цветов, где каждый цвет указан один раз).
