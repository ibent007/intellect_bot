1. Порядок элементов: список сохраняет порядок добавления, множество хранит элементы в произвольном порядке.
2. Повторяющиеся элементы: список допускает дубликаты, множество хранит только уникальные значения.
3. Когда выбирать: список — когда важен порядок и допустимы повторы (например, расписание занятий по дням недели). Множество — когда важны только уникальные значения (например, список языков, которые ты знаешь).
