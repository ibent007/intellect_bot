1. Список сохраняет порядок элементов в том виде, в котором они были добавлены. Множество не гарантирует порядок.
2. Список допускает повторяющиеся элементы. Множество хранит только уникальные значения.
3. Список — когда важен порядок или нужны дубликаты, например список покупок, где два яблока — это два разных пункта. Множество — когда важна уникальность и быстрый поиск, например набор ключей на связке: каждый ключ один, порядок не важен.
